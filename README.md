# Stopwatch Web Application — Task 02

Responsive stopwatch made for Prodigy Infotech Task-02.

### Features
- Start / Pause / Resume
- Reset
- Lap-time tracking
- Responsive desktop and mobile UI
- HTML5, CSS3 and Vanilla JavaScript
- No external libraries

### Run in VS Code
1. Extract the ZIP.
2. Open `Stopwatch_Web_Application_Task02` in VS Code.
3. Open `index.html`.
4. Right-click → **Open with Live Server**.
5. The stopwatch opens in your browser.

You can also open `index.html` directly in Chrome.
